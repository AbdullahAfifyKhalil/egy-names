# Examples

One folder per live library. Same engine. Each script stays in its own language.

| Folder | Library |
|---|---|
| [`python/`](python/) | `pip install egy-names` |
| [`typescript/`](typescript/) | `npm install egy-names` |
| [`php/`](php/) | `composer require afify/egy-names` |
| [`dart/`](dart/) | `dart pub add egy_names` |
| [`java/`](java/) | Maven Central `io.github.abdullahafifykhalil:egy-names:0.3.6` |
| [`csharp/`](csharp/) | `dotnet add package egy-names` |
| [`swift/`](swift/) | Swift PM `EgyNames` |
| [`cpp/`](cpp/) | C++20 header + catalog |
| [`faker-python/`](faker-python/) | `pip install faker-egy-names` |
| [`faker-php/`](faker-php/) | `composer require afify/faker-egy-names` |

`is_valid` is true only for a personal name in the book. `الله` stays in the index for split/lookup. It is not a person's name.

Gender and religion read the first personal, non-lineage token. `identify` / `identify_all` are Python only — book first, then the fallback model, marked `inferred`.

Product page: [afify.co/egy-names](https://afify.co/egy-names)
